Help

Overview

LastMilePDF edits the accessibility tag tree (the PDF's logical structure tree) of a PDF, plus its outline (bookmarks) and document metadata. Open a PDF, and if it already has a tag tree, the Page Preview pane shows the current page, the Tag Tree pane shows its structure, and the Tag Properties pane lets you edit whatever tag is selected. A PDF with no tag tree can still be viewed, but there is nothing to edit until it has been tagged elsewhere.

Selecting & navigating tags

Click a row in the Tag Tree to select it and jump the preview to it; the matching content is highlighted on the page. Shift+click selects a range, Ctrl/Cmd+click adds or removes a single row from the selection, and the ↑/↓ arrow keys move through the tree (Shift+↑/↓ extends the selection). ←/→ collapse or expand the selected tag's children — when the tree is filtered to Headings, they instead step the heading level. Drag a row onto another to reorder it or move it under a new parent; Ctrl/Cmd+↑/↓ moves the selection earlier/later among its siblings without touching the mouse.

The dropdown above the tree filters it to Figures, Headings, or Table tags, or back to All. This is a view filter only — it doesn't change the document.

Tag Properties panel

Editing the selected tag(s):

Role
The tag's structure type (P, H1–H6, Table, Figure, and so on). Type or pick from the suggestion list.
Language
An optional language override (e.g. en-US) for just this tag's content. When the document root (/Document) is selected, this instead shows and edits the PDF's overall primary language.
Scope / Column span / Row span
Shown for TH (table header) cells — whether the header applies to its Row, Column, or Both, and how many columns/rows the cell spans.
Title / Author
Shown when the document root is selected — edits the PDF's document metadata, not a tag.
Alt text
The description read aloud for a Figure or Formula tag.
Actual text
Replacement text a screen reader speaks instead of the tag's real content. Pull Content copies the tag's own extracted text in as a starting point.
Table preview
Shown for Table tags — a quick read-only preview, with a Table Editor button that opens the full editor (see below).

Tagging shortcuts

With one or more tags selected, single-key shortcuts apply a role or restructure the selection: 1–6 set heading level H1–H6, P converts to Paragraph, I sets List Item, D/H set Table Cell/Table Header Cell, and F converts to a Figure, flattening its contents down to plain content leaves. L groups the whole selection into a new List, T groups it into a new Table (keeping any existing TH/TR tags, turning the rest into TD), and R groups it into a single Table Row the same way. See the Shortcuts dialog for the complete list, including selection and reordering keys.

Toolbar tools

Kill Divs
Removes every Div tag in the document, keeping its contents in place — useful for flattening structure that's more nested than it needs to be.
Scope Tables
Looks at each table's header shape and sets Row/Column/Both scope on its TH cells automatically.
Smartifact
Finds image leaves that are the same size as their page — typically full-page scan backgrounds — and marks them as artifacts (decorative, skipped by screen readers).
Add Figure
Toggles draw mode: drag a rectangle on the page preview to tag whatever's underneath as a new Figure. Press Esc to cancel.
Walk
Steps through the tag tree automatically, one tag at a time, so you can read along with the preview. While walking, +/- adjust the speed (remembered for next time) and any other key stops it.
Verify
Runs a set of common PDF accessibility checks (tagging, title, language, headings, lists, tables, alternate text, bookmarks) and opens the results in their own window. Click a listed issue to jump straight to the offending tag.

Table Editor

Open it from a selected Table tag's Table Preview. It lays the table out as a grid; select one or more cells to edit their header Scope, Column span, and Row span together, or convert the selection between Header (TH) and Data (TD) cells.

Bookmarks

The Bookmarks tab shows the PDF's outline. Click a bookmark to jump to its page, double-click to rename it, or press Delete to remove the selected one. Generate clears the existing outline and builds a fresh one from the document's headings.

Saving & undo

Ctrl/Cmd+Z undoes and Ctrl/Cmd+Y (or Ctrl/Cmd+Shift+Z) redoes the last tag edit — this history is independent of any text field you might be typing in. Ctrl/Cmd+S saves; the first save (or Ctrl/Cmd+Shift+S, Save As) asks where to write the file, and later saves write straight back to that path.
